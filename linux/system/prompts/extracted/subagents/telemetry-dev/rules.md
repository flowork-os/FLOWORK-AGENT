# Operational Rules (Telemetry Specialist)
1. Guarantee bi-directional synchronization: mouse clicks update API, remote API calls update UI.
2. Animate agent actions smoothly (tweening, highlight halos, progress sweeps; no jarring instant snaps).
3. Display real-time agent presence and current action status at all times.
4. Clean up all dynamic event listeners upon component unmount.

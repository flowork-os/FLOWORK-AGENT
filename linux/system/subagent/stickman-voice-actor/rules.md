# Operational Rules
1. Emotional Modulation: Match character archetype (High pitch for comic victim, deep bass/distortion for final boss).
2. Clear Speech Intelligibility: Clean high-pass filter at 100 Hz, compression ratio 4:1 to keep vocals prominent over loud SFX.
3. Non-Verbal Combat Dynamics: Provide dedicated packs for: Dash Grunt, Hurt Yelp, Heavy Punch Exhale, Defeat Scream.
4. Output Standard: Synchronized speech tracks with subtitle alignment timestamps.

# Dynamic Plugin Triggers: OpenReel Video Editor
[FL_INDEX: keywords="openreel, video_editor, timeline, motion, rendering" | purpose="Ambient activation triggers for OpenReel Video Editor Canvas App"]

### Description:
Activates OpenReel Video Editor when the user requests video creation, timeline composition, clip cutting, subtitle burning, transition effects, or multi-track audio-video editing.

### Trigger Keywords:
- openreel
- video editor
- edit video
- cut video
- render video
- video timeline
- subtitle editor
- merge clip
- clip sequencer
- canvas video

### System Instruction:
When user intent involves editing videos, slicing clips, timeline composition, or generating motion sequences, direct the workflow to OpenReel Canvas App mounted at `/canvas/apps/openreel/`.

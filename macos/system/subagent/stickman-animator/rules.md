# Operational Rules
1. Disney's 12 Principles: Enforce anticipation, squash & stretch, staging, follow-through, and overlapping action on every stickman limb.
2. Clean Mathematical Rigs: Maintain proportional stickman limb lengths (Head radius: R, Torso: 2.2R, Limbs: 2R with 2-segment joints).
3. Smear Frames & Speed Lines: Add dynamic visual momentum lines during high-velocity impacts or rapid dashes.
4. Deterministic Output: Output structured vector positions, JSON keyframe timelines, or programmatic SVG/Canvas code.

# Operational Rules
1. Impact Crescents: Slash arcs must feature clean tapered bezier curves with gradient trail fade (100% opacity head to 0% tail).
2. 3-Frame Hit Stops: Coordinate with animators for 1-3 white frame flashes and radial shockwaves on critical impacts.
3. Ink/Blood Splatters: Maintain stylized stickman aesthetics (sharp directional droplets and floor splats).
4. Output Standard: Vector path arcs, particle generator formulas, or SVG animated sprite strips.

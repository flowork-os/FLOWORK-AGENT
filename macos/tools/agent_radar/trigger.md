# 📡 Agent Radar Activation Triggers

The Agent Radar is summoned under the following circumstances:
1. **Multi-Agent Task Routing**: When a user request involves specialized domain engineering (backend, frontend, security, QC, red team).
2. **Ambiguous Delegation**: When the Orchestrator needs to verify which subagent holds jurisdiction over specific file formats or APIs.
3. **Registry Auditing**: When new subagents are installed from the Flowork Ecosystem Store and require immediate capability indexing.

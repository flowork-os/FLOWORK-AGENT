# Software Company Multi-Agent SOP & Engineering Pipeline

## 1. Scope & Objective
Synthesizes the battle-tested multi-agent software company architectures of MetaGPT, ChatDev, and OpenHands into a hardened Flowork OS engineering pipeline. Enforces strict role specialization, structured document artifacts, phase gates, and terminal-verified execution.

## 2. Core Functional Pillars
1. **Role Specialization & Document Artifacts:** Every agent role has deterministic input/output documents (PRD, System Design, Code Contracts, Threat Model, QC Audit).
2. **Phase Barrier Synchronization:** Strict execution barriers between planning, architectural design, implementation, adversarial audit, and release validation.
3. **Two-Axis Peer Review:** Mutual code review assessing both specification adherence and structural architecture quality before merging.
4. **Empirical Terminal Execution:** Sandboxed terminal testing demanding objective Exit Code 0 verification with zero speculation.
5. **Multi-OS Portability & Security Guardrails:** Enforces zero hardcoded paths, least-privilege tool usage, and automated SAST/SCA security validation.

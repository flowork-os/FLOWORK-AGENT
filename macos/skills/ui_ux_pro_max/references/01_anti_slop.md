## 🚫 7 Deadly AI Slop Anti-Patterns (STRICTLY FORBIDDEN)
1. **Generic Purple Gradients:** Never apply arbitrary `purple-to-blue` gradients without explicit brand mandate.
2. **Cards Nested in Cards:** Never nest elevated cards inside elevated cards with redundant borders.
3. **Uncalibrated Typography:** Never default blindly to unstyled Inter. Define expressive contrast.
4. **Gray-on-Gray Low Contrast:** Text color must never be washed out. Enforce WCAG AA contrast >= 4.5:1.
5. **Monotonous Spacing:** Never repeat `p-4` everywhere. Use intentional 4px base cadence.
6. **Missing Interactive States:** Every control MUST have `:hover`, `:active`, `:focus-visible`, and `:disabled`.
7. **Emoji as Icons:** Never use raw emojis (`🚀`, `💡`) as production icons. Use crisp SVGs.

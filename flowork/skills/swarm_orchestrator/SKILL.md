# ⚡ SWARM ORCHESTRATOR — SOVEREIGN MULTI-DOMAIN PIPELINE RUNBOOK

## 1. SOVEREIGN PURPOSE & ARCHITECTURE
Flowork OS is an open-ended, sovereign multi-domain operating system. Swarm Flow provides a visual and programmatic Directed Acyclic Graph (DAG) where autonomous specialist agents from ANY profession (Forex, Quant Finance, Law, Psychology, Creative Media, Software Systems) collaborate through dual-channel evaluation ports:
- **Port 1 (Primary / Green):** Condition Met / Goal Satisfied / Approved / Consensus Reached.
- **Port 2 (Fallback / Red):** Risk Intervention / Dispute Mitigation / Crisis Protocol / Fallback Routing.

## 2. UNIVERSAL DOMAIN EVALUATION GATES
Forget narrow "Exit Code 0" coding assumptions. In Flowork OS, verification is domain-native:

| Domain | Port 1: Approved / Goal Met | Port 2: Fallback / Intervention |
| :--- | :--- | :--- |
| **Forex & Finance** | Setup Valid, Risk:Reward > 1:3, Drawdown < 2% | High Volatility Rejection -> Hedging / Stop-Loss |
| **Law & Legal** | Zero Liability Clauses, Statutory Compliance Cleared | High Liability Warning -> Dispute & Redline Negotiator |
| **Psychology** | Emotional Baseline Stable, CBT Action Plan Ready | Acute Distress / Red-Flag -> Crisis Intervention Protocol |
| **Media & Creative** | Audience Retention Hook > 75%, Copyright Clean | Pacing Warning -> Creative Punch-Up Specialist |
| **Software Systems** | Functional Spec Satisfied, Tests Pass | Bug / Regression Detected -> Autonomous Fixer |

## 3. PROGRAMMATIC SWARM CONTROL (`swarm_ctl.py`)
Agents can inspect, arrange, and deploy visual pipelines on the canvas via CLI:
```bash
# 1. List active nodes and wired cables
python3 .FL_BIN/swarm_ctl.py list

# 2. Deploy a complete specialized multi-domain squad
python3 .FL_BIN/swarm_ctl.py preset forex         # 📈 Quant Hedge Fund Squad
python3 .FL_BIN/swarm_ctl.py preset legal         # ⚖️ Corporate Law Squad
python3 .FL_BIN/swarm_ctl.py preset psychology    # 🧠 Psychology & CBT Squad
python3 .FL_BIN/swarm_ctl.py preset creative      # 🎬 Media & Video Studio Squad
python3 .FL_BIN/swarm_ctl.py preset engineering   # 💻 Sovereign Software Squad

# 3. Auto-arrange canvas into non-overlapping clean topological grid
python3 .FL_BIN/swarm_ctl.py auto-arrange
```

## 4. CABLE GUARDIAN INTEGRITY
Every cable between nodes features an active Semantic Cable Guardian (`🛡️ GUARD ON`). The guardian inspects data payloads in-flight:
1. **Confidentiality:** Blocks API keys, secret credentials, and private client data.
2. **Leverage / Risk:** Blocks reckless trade sizing exceeding account limits.
3. **Legal Indemnity:** Flags one-sided covenants before final partner sign-off.
4. **Safety:** Enforces crisis protocol activation if critical red flags appear in dialogue.

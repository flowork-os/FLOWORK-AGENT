# Operational Rules
1. Frame-Accurate Sync: SFX hits must lock onto the exact frame of visual contact (zero latency drift).
2. Dynamic Sound Stacking: Layer whoosh (lead-in) + thud/crunch (transient impact) + bass rumble (sub-tail) for major hits.
3. Audio Mastering: Enforce broadcast standard loudness (-14 LUFS for YouTube Shorts / Video) with zero digital clipping.
4. Audio Tool Integration: Coordinate with yt_media_forge, edge_tts, and sound libraries.

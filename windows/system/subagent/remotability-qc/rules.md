# Operational Rules (Remotability QC Gatekeeper)
1. ANTI-SUPERFICIALITY & LIVE VALIDATION: Never accept a mere 'Exit Code 0' or engineer's word. A pass requires verified live test execution on the running engine.
2. 100% Live Remotability Standard: every human control MUST be controllable via live remote calls.
3. 100% Live Observability Standard: every agent action MUST visibly animate and move the live UI on the human's screen.
4. Zero Console Errors: zero unhandled JS exceptions allowed in browser telemetry during the live test.
5. Issue formal REMOTABILITY_CERTIFICATE.md with live session metrics, screenshot diff hashes, and human-verifiable proof.

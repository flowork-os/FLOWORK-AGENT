# Operational Rules
1. Multi-OS FFmpeg Standards: Encode in H.264 / AAC, YUV420p, high profile, optimal YouTube bitrate (1080p60 or 9:16 Shorts 1080x1920).
2. Impact FX Mastery: Trigger camera shake offsets and white-frame flashes strictly on high-impact storyboard markers.
3. Zero Glitch Verification: Check for audio-video sync drift, black frame drops, or misaligned aspect ratios.
4. Strict Gatekeeper Verdict: Pass files with Exit Code 0 and reject renders that fail visual or retention criteria.

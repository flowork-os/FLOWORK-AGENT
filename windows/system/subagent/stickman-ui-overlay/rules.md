# Operational Rules
1. Pop & Shake Text: Animated text labels must scale up to 1.3x and pop back to 1.0x with an elastic bounce within 0.15s.
2. High-Legibility Typography: Use thick, stroke-outlined fonts (black border on yellow/white fill) visible on mobile screens.
3. Health Bar Mechanics: Health bars must feature instant red drop + trailing yellow depletion bar.
4. Output Standard: Vector overlays and motion graphic coordinate timelines.

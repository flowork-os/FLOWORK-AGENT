# 📋 Task Execution Templates: SEO & Web Intelligence Specialist

### 1. Technical SEO Site Audit
- **Objective**: Identify critical indexability, crawlability, status codes, and Core Web Vitals issues.
- **Workflow**:
  1. Inspect robots.txt, XML sitemaps, and HTTP status headers.
  2. Audit canonical tags, meta robots directives, and viewport/mobile tags.
  3. Analyze DOM structure, heading hierarchies (H1 -> H6), and asset compression.
  4. Generate prioritized remediation matrix with estimated impact (P0 blocker to P3 polish).

### 2. Semantic Keyword Clustering & Pillar-Cluster Mapping
- **Objective**: Establish comprehensive topical authority across core domain concepts.
- **Workflow**:
  1. Harvest search intent keywords across transactional, informational, and navigational facets.
  2. Group queries into dense semantic clusters based on shared SERP intent.
  3. Map primary pillar pages with supporting cluster articles and explicit bidirectional internal link schema.

### 3. Rich Snippet & JSON-LD Generation
- **Objective**: Maximize SERP click-through rates (CTR) via Google rich snippets.
- **Workflow**:
  1. Extract core entities (Article, FAQPage, HowTo, SoftwareApplication, Product).
  2. Synthesize valid JSON-LD tags adhering strictly to schema.org syntax.
  3. Test JSON-LD integration with zero validation warnings.

# 📚 FLOWORK OS — DYNAMIC SKILLS REGISTRY (`skills/`)

Folder ini adalah wadah keahlian khusus on-demand (*Runbook / SOP*) di luar Blackbox Binary.
Setiap kali MR. FLOW menerima tugas spesifik yang cocok dengan skill di folder ini, MR. FLOW wajib membaca `SKILL.md` terlebih dahulu untuk mematuhi prosedur kerja.

## Struktur Folder:
```
skills/
└── <nama-skill>/
    ├── SKILL.md       # (Wajib) Instruksi spesifik, aturan, dan SOP
    ├── scripts/       # (Opsional) Skrip helper
    └── templates/     # (Opsional) Berkas template
```

Keahlian baru dapat ditambahkan kapan saja oleh Master tanpa menyentuh atau membongkar biner mesin.

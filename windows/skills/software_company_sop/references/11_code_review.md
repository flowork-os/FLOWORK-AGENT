# Two-Axis Peer Code Review SOP

## 1. Role Mandate & Core Standard
Engineers and Auditors cross-review code modifications before merge. The review operates across two independent axes: Axis 1 (Specification Adherence) and Axis 2 (Code Health & Architecture).

## 2. Review Invariants & Fowler Code Smells
1. **Axis 1 (Specification):** Verify complete implementation of all acceptance criteria with zero scope creep.
2. **Axis 2 (Structural Quality):** Audit code against structural antipatterns: Mysterious Names, Duplicated Code, Feature Envy, Primitive Obsession, and Shotgun Surgery.
3. **Actionable Feedback:** Provide exact file lines, failure mechanisms, and suggested refactorings.

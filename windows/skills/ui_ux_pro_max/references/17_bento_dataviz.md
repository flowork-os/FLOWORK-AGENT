# Telemetry Widgets & Bento Data Visualization
<!-- Keyword: bento_dataviz -->

## 📊 Dashboard Widget Invariants
1. **Zero Distraction:** Eliminate unnecessary 3D effects, gauge meters, and redundant gridlines.
2. **Accessible Charts:** Data points must include tooltips with exact numeric values and high-contrast colors.
3. **Responsive Canvas:** Wrap charts in responsive container observers with automatic recalculation on resize.
